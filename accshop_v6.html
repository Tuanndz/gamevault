⚠️ Giữ bí mật API Key. Ai có key này có thể truy cập tài khoản của bạn.

📖 API Endpoints

GET/api/products — Lấy danh sách sản phẩm
https://gamevault.vn/api/products?api_key=YOUR_KEY
POST/api/purchase — Mua sản phẩm
https://gamevault.vn/api/purchase
Body: {"api_key":"KEY","product_id":1,"quantity":1}
GET/api/balance — Kiểm tra số dư
https://gamevault.vn/api/balance?api_key=YOUR_KEY
POST/api/webhook — Nhận thông báo
https://gamevault.vn/api/webhook/zalo

🤖 Kết nối Bot Zalo

Cho phép khách hàng mua hàng trực tiếp qua Zalo OA của bạn:

https://gamevault.vn/api/webhook/zalo/YOUR_KEY
📝 Hướng dẫn: Vào Zalo OA → Cài đặt → Webhook → Điền URL ở trên → Copy Access Token về đây → Lưu.

🤖 Zalo Bot - Kết nối bằng Cookies

Dán Cookies + CSRF IEMI JS từ Zalo Web vào đây để kết nối bot không cần API key chính thức.

📝 Hướng dẫn: Mở Zalo Web → F12 → Network → gửi tin nhắn → tìm request → copy cookies và IEMI/csrf từ request header.
